## Install the CLI

<Tabs>
  <Tab label="npm">
    ```bash
    npm install -g @team/cli
    ```
  </Tab>
  <Tab label="pnpm">
    ```bash
    pnpm add -g @team/cli
    ```
  </Tab>
</Tabs>

| Command        | What it does            |
| -------------- | ----------------------- |
| `team init`    | Scaffold a new project  |
| `team deploy`  | Deploy to staging       |
