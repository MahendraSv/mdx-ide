# Slides in MDX IDE

Press **⌘⇧↵** to present, then use the arrow keys.

---

## Keys

| Key | Action |
|---|---|
| → or Space | Next slide |
| ← | Previous slide |
| G | All slides |
| R | Reset this slide |
| Esc | Stop presenting |
